**Fortune Cookie Wisdom for Developers** — one original fortune-cookie line for a software developer, 100 characters, written fresh for this bounty. It turns the oldest developer superstition on its head: the bug that only ever appears on Fridays is not haunting you, it is quietly teaching you to deploy on Tuesdays instead.

`main.py` is its deterministic runner: it writes the fortune to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness.

## Run it

```sh
python3 main.py
```
